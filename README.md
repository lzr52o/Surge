## 使用方法

在 Surge 中添加远程模块，填入对应模块的 Raw 链接，格式如下：

https://raw.githubusercontent.com/lzr52o/Surge/master/模块文件名.sgmodule

例如 Line去广告：

https://raw.githubusercontent.com/lzr52o/Surge/master/Line%E5%8E%BB%E5%B9%BF%E5%91%8A.sgmodule
